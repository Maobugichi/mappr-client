The application bundles the same unmodified WOFF2 files previously fetched by
`next/font/google`. Keeping the files in source removes the Google font loader
from development and production builds. `fonts.css` preserves the original
font weights, Unicode subsets, fallback metrics and CSS variable names.

Upstream licenses:

- [Space Grotesk](https://github.com/google/fonts/blob/main/ofl/spacegrotesk/OFL.txt)
- [IBM Plex Sans](https://github.com/google/fonts/blob/main/ofl/ibmplexsans/OFL.txt)
- [JetBrains Mono](https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/OFL.txt)
